这段代码分成两部分：

1. 用 **01 背包**，把所有点分成度数和相等的两组。
2. 在两组之间连边，让每个点的度数满足要求。

最关键的题目条件是：**允许重边，但不允许自环**。这让第二部分的构造变得很简单。

下面结合例子逐段解释：

```text
n = 4
d = [2, 1, 2, 1]
```

也就是点 1、2、3、4 的目标度数分别是 2、1、2、1。

## 一、为什么要先找“度数和相等”的两组？

二分图要求把点分成左右两组 \(U,V\)，每条边都连接左边一个点与右边一个点。

例如连接一条边：

```text
左侧点 u —— 右侧点 v
```

这条边会让：

- 左侧的度数和增加 1；
- 右侧的度数和增加 1。

所以，一个有 \(m\) 条边的二分图一定满足：

\[
\sum_{i\in U}d_i=m,\qquad \sum_{i\in V}d_i=m
\]

如果所有点的度数和为 \(S\)，那么：

\[
S=2m
\]

因此必须把点分成两组，使每组的度数和都是 \(S/2\)。

对于例子：

```text
d = [2, 1, 2, 1]
S = 6
每组需要的度数和 = 3
```

一种分法是：

```text
左组：点 1、点 2，度数和 2 + 1 = 3
右组：点 3、点 4，度数和 2 + 1 = 3
```

接下来只要在两组之间连边即可。

## 二、读入数据并计算度数和

```cpp
int n;
cin >> n;

vector<int> d(n + 1);
int sum = 0;

for (int i = 1; i <= n; ++i) {
    cin >> d[i];
    sum += d[i];
}
```

变量含义：

| 变量 | 含义 |
|---|---|
| `n` | 点的数量 |
| `d[i]` | 点 `i` 需要达到的度数 |
| `sum` | 所有点的度数之和 |

`d` 开成 `n + 1`，是为了让数组下标直接对应点的编号 `1~n`，下标 0 不使用。

对于例子，读入后：

```text
d[1] = 2
d[2] = 1
d[3] = 2
d[4] = 1
sum = 6
```

## 三、度数和为奇数，直接无解

```cpp
if (sum % 2) {
    cout << -1 << '\n';
    return 0;
}

int target = sum / 2;
```

每条边都会贡献两个度数，因此任何无向图的度数和都必须是偶数。

如果 `sum` 为奇数，不仅二分图构造不出来，普通无向图也构造不出来。

但是，**度数和为偶数只是必要条件，不保证一定有解**。

例如：

```text
d = [2, 2, 2]
sum = 6
target = 3
```

从三个 2 中选取若干个，无法凑出 3，所以不能将点分成度数和相等的两组。

这就需要接下来的背包判断。

## 四、用 `from` 数组记录背包状态和构造路径

```cpp
vector<int> from(target + 1, -1);
from[0] = 0;
```

通常的 01 背包可能使用：

```cpp
dp[s] = 是否能选出若干个点，使度数和为 s
```

但本题不仅需要判断，还需要知道**具体选了哪些点**。

所以代码使用 `from[s]` 同时完成两个任务：

| `from[s]` | 含义 |
|---|---|
| `-1` | 当前无法凑出和 `s` |
| 某个点编号 `i` | 可以凑出 `s`，首次凑出时最后加入的是点 `i` |

例如：

```text
from[3] = 2
```

表示凑出度数和 3 时，最后加入的是点 2。

点 2 的度数为 `d[2]`，所以加入它之前，已经凑出了：

\[
3-d[2]
\]

这就能沿着记录倒推，找出整个点集。

初始化：

```cpp
from[0] = 0;
```

因为一个点都不选，就能凑出 0。

这里的 0 是特殊标记，不代表真的选择了点 0。

## 五、01 背包的状态转移

```cpp
for (int i = 1; i <= n; ++i) {
    for (int s = target; s >= d[i]; --s) {
        if (from[s] == -1 && from[s - d[i]] != -1) {
            from[s] = i;
        }
    }
}
```

把每个点看成一个“物品”，它的重量就是该点的度数 `d[i]`。

我们要从这些物品中选若干个，使总重量恰好为 `target`。

### 1. 外层循环：考虑选择哪个点

```cpp
for (int i = 1; i <= n; ++i)
```

依次考虑点 1、点 2……点 n。

每个点最多只能放入左组一次，所以是 **01 背包**。

### 2. 内层循环：尝试凑出度数和 `s`

```cpp
for (int s = target; s >= d[i]; --s)
```

如果想把点 `i` 加入一个总和为 `s` 的集合，那么在加入它之前，需要先凑出：

```cpp
s - d[i]
```

因此有转移：

\[
\text{能凑出 }s-d_i
\quad\Longrightarrow\quad
\text{加入点 }i\text{ 后能凑出 }s
\]

### 3. 为什么 `s` 必须倒序？

因为每个点只能用一次。

假设当前只有一个点，它的度数是 2，目标是 4。

如果正序遍历：

```text
s = 2：由 0 + 2 得到 2
s = 4：又由刚得到的 2 + 2 得到 4
```

同一个点被用了两次，这是错误的。

倒序遍历则是：

```text
s = 4：此时还不能凑出 2，所以不能得到 4
s = 2：由 0 + 2 得到 2
```

这样就保证当前点最多被使用一次。

### 4. `if` 的两个条件分别是什么意思？

```cpp
if (from[s] == -1 && from[s - d[i]] != -1)
```

第一个条件：

```cpp
from[s] == -1
```

表示还没有找到凑出 `s` 的方法。

第二个条件：

```cpp
from[s - d[i]] != -1
```

表示可以凑出 `s - d[i]`。

同时满足，就可以加入点 `i`，得到 `s`：

```cpp
from[s] = i;
```

找到一种方法后不再覆盖，是为了保留稳定的还原路径；题目只需要任意一个解。

## 六、用例子模拟背包

仍然考虑：

```text
d = [2, 1, 2, 1]
target = 3
```

初始化：

```text
from[0] = 0
from[1] = -1
from[2] = -1
from[3] = -1
```

### 考虑点 1：度数为 2

先尝试 `s = 3`：

```text
需要先凑出 3 - 2 = 1
但 1 不可达，无法转移
```

再尝试 `s = 2`：

```text
需要先凑出 2 - 2 = 0
0 可达，所以 from[2] = 1
```

此时：

```text
from = [0, -1, 1, -1]
```

### 考虑点 2：度数为 1

先尝试 `s = 3`：

```text
3 - 1 = 2
2 已经可达，所以 from[3] = 2
```

说明：

```text
原来选点 1，度数和为 2
现在再选点 2，度数和变成 3
```

继续尝试 `s = 2`，因为已经可达，不覆盖。

最后尝试 `s = 1`：

```text
1 - 1 = 0
0 可达，所以 from[1] = 2
```

此时：

```text
from = [0, 2, 1, 2]
```

状态变化汇总：

| 已考虑的点 | 可达的度数和 |
|---|---|
| 无 | 0 |
| 点 1，度数 2 | 0、2 |
| 点 2，度数 1 | 0、1、2、3 |
| 点 3，度数 2 | 0、1、2、3 |
| 点 4，度数 1 | 0、1、2、3 |

`target = 3` 已经可达。

## 七、判断是否能分组

```cpp
if (from[target] == -1) {
    cout << -1 << '\n';
    return 0;
}
```

背包结束后，如果仍然无法凑出 `target`，说明不存在一组点的度数和等于总和的一半。

而任何二分图都必须存在这样的分组，所以输出 `-1`。

注意：这里判断的是**点的分组**，还没有开始连边。

## 八、沿着 `from` 数组还原左组

```cpp
vector<bool> inLeft(n + 1, false);

for (int s = target; s > 0; ) {
    int i = from[s];
    inLeft[i] = true;
    s -= d[i];
}
```

`inLeft[i]` 表示点 `i` 是否属于左组：

```text
true  → 左组
false → 右组
```

还原从 `target` 开始。

对于例子：

```text
target = 3
from[3] = 2
```

说明最后加入的是点 2：

```cpp
inLeft[2] = true;
s -= d[2];
```

因为 `d[2] = 1`：

```text
s = 3 - 1 = 2
```

然后：

```text
from[2] = 1
```

说明此前加入了点 1：

```cpp
inLeft[1] = true;
s -= d[1];
```

因为 `d[1] = 2`：

```text
s = 2 - 2 = 0
```

还原结束，得到：

```text
左组：点 1、点 2
```

这里每次 `s` 都减去一个正数，所以一定会结束。

这条路径也不会重复选点：倒序背包保证建立状态时，前驱只使用此前考虑过的点；`from` 又只在首次可达时赋值，路径不会被后续覆盖。

## 九、建立左右两组的编号数组

```cpp
vector<int> left, right;

for (int i = 1; i <= n; ++i) {
    if (inLeft[i]) left.push_back(i);
    else right.push_back(i);
}
```

将点的编号分别放入两个数组。

例子中：

```cpp
left  = {1, 2};
right = {3, 4};
```

注意，数组中保存的是**点编号**，不是度数。

例如：

```cpp
left[0] = 1;
d[left[0]] = d[1] = 2;
```

左组度数和等于 `target`，其余点的度数和则为：

\[
sum-target=target
\]

所以右组也满足要求。

## 十、输出边数

```cpp
cout << target << '\n';
```

二分图每条边恰好消耗左组的一个度数。

左组的度数和是 `target`，所以最终边数就是 `target`。

例子中：

```text
输出边数 3
```

允许重边时，多条连接同一对点的边也分别计数。

## 十一、用双指针构造边

```cpp
size_t i = 0, j = 0;

while (i < left.size() && j < right.size()) {
    int u = left[i], v = right[j];
    int cnt = min(d[u], d[v]);

    for (int k = 0; k < cnt; ++k) {
        cout << u << ' ' << v << '\n';
    }

    d[u] -= cnt;
    d[v] -= cnt;

    if (d[u] == 0) ++i;
    if (d[v] == 0) ++j;
}
```

这里开始，`d[x]` 的含义变为：

> 点 `x` 还需要多少条边。

### 1. `i` 和 `j` 指向当前待处理的点

```cpp
int u = left[i], v = right[j];
```

- `u` 是当前左组的点；
- `v` 是当前右组的点。

因为它们分属两个不相交的点集，所以一定有：

```text
u != v
```

因此不会出现自环。

`size_t` 是容器 `.size()` 返回值对应的无符号整数类型，这里用于数组下标。

### 2. 为什么取两个剩余度数的最小值？

```cpp
int cnt = min(d[u], d[v]);
```

如果：

```text
u 还需要 5 条边
v 还需要 2 条边
```

那么它们之间最多再连 2 条，否则点 `v` 的度数就超了。

因此：

```text
cnt = 2
```

连接后：

```text
u 还需要 3 条边
v 已经满足
```

至少有一个点会在本轮处理完。

### 3. 实际输出重边

```cpp
for (int k = 0; k < cnt; ++k) {
    cout << u << ' ' << v << '\n';
}
```

例如 `u = 1`、`v = 3`、`cnt = 2`，输出：

```text
1 3
1 3
```

这表示点 1 与点 3 之间有两条边。

**这一步依赖题目允许重边。** 如果题目要求简单图，就不能这样做，分组度数和相等也不再足以保证有解。

### 4. 扣除已经满足的度数

```cpp
d[u] -= cnt;
d[v] -= cnt;
```

每连接一条边，两个端点的剩余度数都减少 1。

连接 `cnt` 条，两端就都减少 `cnt`。

### 5. 哪个点处理完，就移动哪个指针

```cpp
if (d[u] == 0) ++i;
if (d[v] == 0) ++j;
```

这里必须使用两个独立的 `if`，不能写成：

```cpp
if (...) ...
else if (...) ...
```

因为两个点可能同时处理完，需要同时移动两个指针。

## 十二、完整模拟连边过程

分组结果：

```text
左组：点 1（剩余 2）、点 2（剩余 1）
右组：点 3（剩余 2）、点 4（剩余 1）
```

第一轮：

```text
u = 1
v = 3
cnt = min(2, 2) = 2
```

输出：

```text
1 3
1 3
```

更新：

```text
d[1] = 0
d[3] = 0
```

两个指针同时前进。

第二轮：

```text
u = 2
v = 4
cnt = min(1, 1) = 1
```

输出：

```text
2 4
```

更新：

```text
d[2] = 0
d[4] = 0
```

所有点都满足目标度数。

完整输出为：

```text
3
1 3
1 3
2 4
```

检查：

| 点 | 相邻的边 | 最终度数 |
|---|---|---:|
| 1 | 两条 `1—3` | 2 |
| 2 | 一条 `2—4` | 1 |
| 3 | 两条 `1—3` | 2 |
| 4 | 一条 `2—4` | 1 |

图虽然不连通，但题目允许不连通，因此合法。

## 十三、为什么这个贪心不会卡住？

构造过程中有一个始终成立的性质：

\[
\text{左组剩余度数和}=\text{右组剩余度数和}
\]

开始时两边都等于 `target`。

每一轮，左右两侧都减去相同的 `cnt`，所以两侧剩余总和仍然相等。

因此，如果左侧已经全部用完，剩余总和为 0，那么右侧的剩余总和也必然为 0。

不会出现：

```text
左边全部满足了，右边还有点缺边
```

并且允许重边，任意当前左点都可以继续和任意当前右点连接，不存在“这对点已经连过，不能再连”的限制。

所以只要背包能找到分组，构造就一定成功。

## 十四、复杂度

设：

\[
S=\sum d_i,\qquad target=S/2,\qquad m=S/2
\]

背包时间复杂度：

\[
O(n\cdot target)=O(nS)
\]

构造时，每轮至少处理完一个点，指针移动总共为 \(O(n)\)，输出 `m` 条边需要 \(O(m)\)。

总时间复杂度为：

\[
O(nS+m)
\]

空间主要用于：

```text
d、inLeft、left、right：O(n)
from：O(S)
```

总空间复杂度：

\[
O(S+n)
\]

题目中 \(n\le100\)、\(d_i\le n-1\)，所以：

\[
S\le100\times99=9900
\]

背包容量最多 4950，边数最多也是 4950，数据量很小。
