这道题可以理解成：**在一个最多 `6×6` 的棋盘里选格子，使选中的格子两两不相邻，并让数字总和最大。**

这里的“相邻”包含上下、左右以及四个斜角。因此，一个格子被选中后，它周围的 8 个格子都不能再选。

我们详细分析前面这版 **DFS＋状态压缩＋记忆化搜索**。

---

先看为什么不直接逐个格子暴力搜索。

每个格子都有两个选择：

```text
选这个格子
不选这个格子
```

最多有 `36` 个格子，如果不考虑剪枝，搜索规模是：

```text
2^36 ≈ 687 亿
```

即使排除不合法方案，直接枚举仍可能重复计算大量相同情况。

这道题有一个很重要的特点：

> 当前行的选择，只会与当前行内部以及上一行发生相邻冲突。

例如，正在处理第 `3` 行时：

```text
第 0 行 ─┐
第 1 行 ─┴─ 不会直接与第 3 行相邻
第 2 行 ─── 需要检查
第 3 行 ─── 当前处理
```

所以，我们可以把“一行怎么选”作为一次决策。

**每层 DFS 决定一行的选择，递归深度最多只有 6。**

---

一行最多 `6` 个格子，可以用一个整数的二进制位表示选择方案：

```text
某一位为 1：选择对应格子
某一位为 0：不选择对应格子
```

代码约定：

```cpp
第 j 列，对应二进制的第 j 位。
```

也就是：

```cpp
mask & (1 << j)
```

结果非零，表示选中了第 `j` 列。

注意，通常书写二进制时，**最右边是第 0 位，对应这里的第 0 列**。

例如，一行有三个数：

| 列号 | 第 0 列 | 第 1 列 | 第 2 列 |
|---|---:|---:|---:|
| 数值 | 5 | 8 | 4 |
| 是否选择 | 选 | 不选 | 选 |

选择方案对应：

```text
mask = 101₂ = 5
```

取得的分数是：

```text
5 + 4 = 9
```

所有状态可以这样枚举：

```cpp
for (int mask = 0; mask < (1 << m); ++mask)
```

因为：

```text
1 << m = 2^m
```

`m = 3` 时，枚举的状态就是：

```text
000 001 010 011 100 101 110 111
```

不过，同一行中不能选左右相邻的格子，所以只有：

```text
000 001 010 100 101
```

这五种合法状态。

其中 `000` 表示整行都不选，也是必须保留的一种方案。

---

如何判断同一行有没有选中相邻格子？

用：

```cpp
mask & (mask << 1)
```

如果结果非零，说明二进制里存在相邻的两个 `1`。

例如：

```text
mask        00110
mask << 1   01100
---------------- 按位与
            00100
```

结果非零，原来的状态中有两个相邻的 `1`，不合法。

而：

```text
mask        00101
mask << 1   01010
---------------- 按位与
            00000
```

结果为零，说明没有相邻的 `1`。

因此，合法状态的筛选代码为：

```cpp
vector<int> states;

for (int mask = 0; mask < (1 << m); ++mask) {
    if ((mask & (mask << 1)) == 0) {
        states.push_back(mask);
    }
}
```

这样，后面 DFS 遍历 `states` 时，同一行内部就一定没有左右冲突。

`m = 6` 时，虽然共有 `64` 个状态，但合法状态只有 `21` 个。

---

接着，需要检查当前行和上一行之间有没有冲突。

设：

```cpp
prev：上一行的选择状态
cur：当前行的选择状态
```

两行之间只可能有三类冲突：

| 表达式 | 检查的冲突 |
|---|---|
| `cur & prev` | 同一列，上下相邻 |
| `cur & (prev << 1)` | 当前列号比上一行选中列号大 1，斜着相邻 |
| `cur & (prev >> 1)` | 当前列号比上一行选中列号小 1，斜着相邻 |

例如，上行选择了中间一列：

```text
上一行： · 选 ·
当前行： ？ ？ ？
```

当前行三个位置都不能选择：

```text
左边：与上一行斜着相邻
中间：与上一行上下相邻
右边：与上一行斜着相邻
```

二进制运算为：

```text
prev        010    禁止同一列
prev << 1   100    禁止一个斜向位置
prev >> 1   001    禁止另一个斜向位置
```

所以代码写成：

```cpp
if (cur & prev) {
    continue;
}

if (cur & (prev << 1)) {
    continue;
}

if (cur & (prev >> 1)) {
    continue;
}
```

只有这三个检查都通过，才能继续向下搜索。

这里移位后产生超出 `m` 位的 `1` 不影响结果，因为合法的 `cur` 在那些位置上都是 `0`。

---

现在定义 DFS：

```cpp
int dfs(int row, int prev)
```

它的准确含义是：

> 已知上一行的选择状态是 `prev`，从第 `row` 行开始，到最后一行，最多还能取得多少分。

这个定义中，“还能”很重要：**返回值不包含前面已经取得的分数。**

例如：

```cpp
dfs(2, 5)
```

表示：

```text
第 1 行已经选择了状态 5，也就是二进制 101。

现在需要计算：
第 2 行到最后一行，最多还能选出多少分。
```

搜索过程可以拆为四步：

1. 枚举当前行的合法状态 `cur`。
2. 检查 `cur` 与上一行的 `prev` 是否冲突。
3. 不冲突，就递归计算 `dfs(row + 1, cur)`。
4. 当前行得分加上后面各行的最优得分，取最大值。

递归转移就是：

```cpp
ans = max(
    ans,
    value[row][cur] + dfs(row + 1, cur)
);
```

其中：

```cpp
value[row][cur]
```

表示当前这一行采用 `cur` 状态时，可以取得多少分。

例如：

```text
当前行： 5 8 4
cur：   101
```

那么：

```cpp
value[row][cur] = 5 + 4 = 9;
```

`value` 可以在搜索之前预处理，避免 DFS 每次都重新计算：

```cpp
for (int row = 0; row < n; ++row) {
    for (int mask : states) {
        for (int j = 0; j < m; ++j) {
            if (mask & (1 << j)) {
                value[row][mask] += a[row][j];
            }
        }
    }
}
```

---

递归边界是：

```cpp
if (row == n) {
    return 0;
}
```

因为行下标是：

```text
0, 1, 2, ..., n - 1
```

当 `row == n` 时，说明所有行已经处理完，没有剩余分数，因此返回 `0`。

初始调用为：

```cpp
dfs(0, 0)
```

含义是：

```text
从第 0 行开始搜索。

它上面没有真正的上一行，可以视为上一行什么都没选，
因此 prev = 0。
```

这样，第 `0` 行可以自由选择任意一个行内合法状态。

---

为什么还需要记忆化？

考虑下面两个不同的搜索分支：

```text
路径 A：
第 0 行选 001
第 1 行选 000
接下来进入 dfs(2, 000)

路径 B：
第 0 行选 101
第 1 行选 000
接下来也进入 dfs(2, 000)
```

它们前面取得的分数可能不同，但是：

```text
从第 2 行开始，剩下的矩阵完全相同；
上一行状态也都是 000。
```

因此，后面最多还能取得的分数一定相同。

既然 `dfs(2, 000)` 的答案一样，就没有必要计算两遍。

用：

```cpp
memo[row][prev]
```

保存它的答案即可。

初始全部设为 `-1`：

```cpp
memset(memo, -1, sizeof(memo));
```

因为题目中的数非负，答案不会是负数，所以：

```text
-1：这个状态还没计算过
≥0：这个状态已经计算过
```

搜索时：

```cpp
int& ans = memo[row][prev];

if (ans != -1) {
    return ans;
}
```

这里的：

```cpp
int& ans
```

是引用，`ans` 就是 `memo[row][prev]` 的别名。

后面修改：

```cpp
ans = 0;
ans = max(ans, ...);
```

实际上就是在修改记忆化数组，不需要最后再写一遍：

```cpp
memo[row][prev] = ans;
```

注意，`ans = 0` 是一个有效答案，不能把它当作“没有计算过”。即使矩阵元素都为正，当上一行占据了某些位置时，剩余行也可能只能不取数。

---

完整代码如下，注释对应上述过程：

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;
int a[6][6];

// 每一行内部没有相邻选择的状态。
vector<int> states;

// value[row][mask]：第 row 行采用 mask 的得分。
int value[6][64];

// memo[row][prev]：上一行状态为 prev 时，
// 从 row 行到最后一行的最大得分。
int memo[6][64];

int dfs(int row, int prev) {
    // 所有行处理完，没有剩余得分。
    if (row == n) {
        return 0;
    }

    int& ans = memo[row][prev];

    // 这个子问题已经求解过。
    if (ans != -1) {
        return ans;
    }

    ans = 0;

    // 枚举当前行的选择方案。
    for (int cur : states) {
        // 上下相邻。
        if (cur & prev) {
            continue;
        }

        // 斜向相邻。
        if (cur & (prev << 1)) {
            continue;
        }

        if (cur & (prev >> 1)) {
            continue;
        }

        // 当前行得分 + 剩余行的最优得分。
        ans = max(
            ans,
            value[row][cur] + dfs(row + 1, cur)
        );
    }

    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--) {
        cin >> n >> m;

        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                cin >> a[i][j];
            }
        }

        // 多组数据之间必须清空。
        states.clear();
        memset(value, 0, sizeof(value));
        memset(memo, -1, sizeof(memo));

        // 预处理同一行内合法的状态。
        for (int mask = 0; mask < (1 << m); ++mask) {
            if ((mask & (mask << 1)) == 0) {
                states.push_back(mask);
            }
        }

        // 预处理每一行在不同状态下的得分。
        for (int row = 0; row < n; ++row) {
            for (int mask : states) {
                for (int j = 0; j < m; ++j) {
                    if (mask & (1 << j)) {
                        value[row][mask] += a[row][j];
                    }
                }
            }
        }

        cout << dfs(0, 0) << '\n';
    }

    return 0;
}
```

题目数字总和不超过 `36×100000 = 3600000`，所以这里使用 `int` 足够。

---

用题目的 `3×3` 全 `1` 样例，跟踪一条最优搜索路径：

```text
1 1 1
1 1 1
1 1 1
```

初始：

```cpp
dfs(0, 000)
```

第 `0` 行选择 `101`：

```text
选 · 选
?  ?  ?
?  ?  ?
```

这一行得 `2` 分，继续：

```cpp
2 + dfs(1, 101)
```

由于上一行左右两边都选了，第 `1` 行所有位置都被限制，只能选择 `000`：

```text
选 · 选
·  ·  ·
?  ?  ?
```

继续：

```cpp
2 + 0 + dfs(2, 000)
```

第 `2` 行上面一行没有选任何数，可以再次选择 `101`：

```text
选 · 选
·  ·  ·
选 · 选
```

继续：

```cpp
2 + 0 + 2 + dfs(3, 101)
```

到达边界：

```cpp
dfs(3, 101) = 0
```

所以最终得到：

```text
2 + 0 + 2 + 0 = 4
```

DFS 也会搜索其他合法选择，并返回所有方案中的最大值。它不会贪心地认为“当前行选得最多，总答案就一定最大”。

例如：

```text
1   1   1
1 100   1
1   1   1
```

这时选择中心的 `100`，比选四个角取得的 `4` 更好。

---

最后，几个容易混淆的地方：

- **为什么不用传 `sum`？**  
  `dfs` 返回的是剩余部分的最优得分，调用者负责加上当前行得分。这样相同 `(row, prev)` 的返回值固定，才能直接记忆化。如果让返回值包含此前累计的 `sum`，却仍只按 `(row, prev)` 缓存，就可能出错。

- **为什么不用撤销选择？**  
  每层通过参数传递 `cur`，没有修改全局“哪些格子已选”的标记。兄弟分支互不影响，因此不需要手动回溯恢复。

- **为什么可以跳过整行？**  
  `000` 是合法状态。有时放弃当前行，能让下一行选择价值更高的数。

- **为什么不检查上上行？**  
  当前行与上上行之间的行号差为 `2`，不属于相邻格子，没有直接冲突。

设合法行状态数量为 `S`：

```text
筛选合法状态：O(2^M)
预处理每行得分：O(N × S × M)
记忆化搜索：O(N × S²)
空间复杂度：O(N × 2^M)，递归栈为 O(N)
```

`M ≤ 6` 时，`S ≤ 21`。记忆化后，每个 `(row, prev)` 只计算一次，每次最多检查 `21` 种当前行状态，因此计算量很小。
